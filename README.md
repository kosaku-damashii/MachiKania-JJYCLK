# MachiKania-JJYCLK

MachiKania type P/PUに電波時計モジュールをデジタルI/Oに接続し、RTCを設定する。<BR>
MICHIKANIAP.INI の 「RTCFILE」を有効にすることによって、SDカード上のファイルへの書き込み時にタイムスタンプの日付もRTCの日付で更新されるようになる。<BR>
ノイズに弱いので、出来る限り窓際近くに置き、現状、type Pよりもtype PUに接続する方がノイズへの影響は少ないように思われ、また電源も電波時計モジュールは外部電源（単3電池3本とか）で供給し、信号とGNDだけをMachiKaniaヘ接続するのが最も安定する様子。<BR>
